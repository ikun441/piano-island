# 琴屿 · 从零开始的钢琴课

基于 HTML、CSS、JavaScript、Three.js 与 Web Audio 的静态交互教程。

## 本地运行

在项目目录运行：

```sh
python3 -m http.server 8765 --directory dist
```

浏览器访问 http://localhost:8765 。请通过 HTTP 服务器运行；直接双击 HTML 可能导致浏览器阻止本地 ES 模块。

## 内容与交互

15 个章节涵盖认识钢琴、坐姿手型、简谱、节奏拍号、旋律指法、高低音谱号、升降号、音阶、三和弦、和弦标记、转位、伴奏踏板与综合演奏。每章有讲解、操作练习、小测与音符演示；学习进度保存在当前浏览器。

三角钢琴为程序化三维模型，含琴盖、琴弦、琴腿、踏板、琴凳与 36 键练习键盘。拖动旋转、滚轮或双指缩放，可切换俯视与演奏视角。模型按键、页面键盘与乐谱共同联动。

音色为 Web Audio 泛音合成钢琴近似音色；不是采样钢琴。支持音量、延音、节拍器、变速、暂停继续、循环及小节跳转。声音需要用户首次点击后启用。

## 最后一章与作品导入

第 15 章以《圣诞快乐，劳伦斯先生》为目标作品，不附带受版权保护的完整原曲谱或 MIDI。内置原创《冬日来信》用于验证同步播放流程。导入你有权使用的钢琴 MIDI 后，可以播放相应作品，并在按音符生成的双谱表上同步高亮。

支持标准 MIDI 格式 0/1、PPQ 时基、running status、速度变化、力度和 CC64 延音；忽略鼓轨。所有轨道合并，音高 C4 及以上置于高音谱表，其余置于低音谱表。MIDI 仅在浏览器本地解析，不上传。限制 2 MB、20,000 音符、4,000 个归一化四分音符拍。

自动谱为练习用途：统一按 4/4 分组，以升号标记黑键，不还原原始调号、拍号、声部、连音线或正式排版。速度变化保留实际时间关系，但转换为统一 BPM 时间轴；因此复杂 MIDI 的谱面节奏不能代替正式乐谱。建议导入简化单钢琴编曲。
